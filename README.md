# Mohammad Taha — Portfolio

Static portfolio (HTML/CSS/JS). Open `index.html` in VS Code with Live Server.

## Customize
- `script.js` top: set `EMAIL`, edit `SKILLS` and `PROJECTS` (add `github` / `live` links per project).
- Put your photo at `assets/images/profile.jpg` and a share image at `assets/images/og.png`.
- Dark/Light theme is saved in the browser.
